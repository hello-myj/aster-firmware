# 流光 · Lightgrain 音效套装

原创合成，统一为轻颗粒、短谐波、柔和展开的声音。滑动 tick 是38ms干净颗粒声；open/close 为相同谐波音色的展开/收束；tune 是两点亮起；tap 更低、更轻。没有长噪声尾巴。

格式：22050Hz 单声道 PCM16 WAV。用途与触发条件见 SOUND-TRIGGERS.md。五种事件分别使用 tick.wav、tap.wav、open.wav、close.wav、tune.wav，直接在模拟 launcher 中随操作播放。

运行 generate_sounds.py 可重生成，Python标准库，无第三方音频。可用于本项目固件及修改。
