# 流光 launcher 音效触发说明

## 文件与事件

- `tick.wav` — 卡片选择反馈。纵向手指拖动或松手后的惯性滚动中，最近中心卡片的索引发生变化时触发；上一项、下一项、滚轮、方向键选择应用时也触发。不是每帧播放，不绑定触摸按下/松开，不为跨过的所有卡片补播。
- `open.wav` — 应用展开。点选当前中央卡片、点按底部拉环，或右拉超过 95px 并释放、正式进入应用时触发一次。拉动尚未达到启动条件、取消手势和相同应用内部刷新不触发。
- `close.wav` — 应用收束。从应用右边缘左拉超过 65px 并释放，或点「收回」/按 Esc 返回主页时触发一次。旧套只用于应用收回；新套也用于关闭频段面板、调音台。
- `tune.wav` — 切换频段。在频段列表确认全部、媒体、玩乐或探索时触发一次；仅打开列表不触发此声。
- `tap.wav` — 轻触确认。打开频段面板或调音台、切换 Wi-Fi/蓝牙/静谧状态、切换动效、重新开启音效时使用。关音效/开静谧后立即静音，不再播放确认声。音量滑杆连续移动不逐次发声。

## 惯性滚动配合

在固件自己的选中索引变化事件中播放 tick，传入当前速度的绝对值（px/ms）。慢速最小播放间隔 95ms；速度超过 0.65px/ms 时最小间隔 160ms。单次增益 `max(0.35, 1 - abs(speed)*0.4)`，再乘系统音量。一次更新即使跨过多张卡片，也最多请求一次声音；被限流的事件丢弃，不能排队追播。

停止时如果仍是同一张选中卡片，不重复播放 tick。下一次手指按下终止惯性，但不额外发声。关闭音效、静谧模式、音量为零时立即停止正在播放的音效。应用启动/返回声优先于滚动 tick；网页最多同时两声，固件建议为 UI 使用独立的短音频通道，避免中断应用音频。

## 音频资源与用法

所有单声文件是 22050Hz 单声道 PCM16 WAV；不要依赖固定 WAV 头长度，解析 data 块后播放，或预先转为裸 PCM。使用非阻塞播放；这些不是用于循环的背景音乐。`specs.json` 给出合成参数；`generate_sounds.py` 可以重新生成。


本音效由项目脚本原创合成，可用于本 launcher 固件及修改；没有引入第三方音频。
