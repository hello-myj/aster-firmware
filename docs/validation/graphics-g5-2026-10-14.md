# G5 图形传输与系统面板验收（2026-10-14）

G5 核心实现、两板基础实机和以下并发范围通过。物理 SPI/DMA 传输故障后的恢复仍未验证，保留为后续复合回归边界；本记录不覆盖不同板批次或发布套件验收。

## 配置与实现

- LCKFB：RGB565，48 KiB 内核堆，IMU 开启，微雪预拷贝关闭。
- 微雪 3.5B：RGB565、40 MHz，内部 RAM 双 8 KiB 预拷贝、48 KiB 内核堆，PSRAM 直接 DMA 关闭；默认板配置不启用 IMU。
- 有界脏区与 SDK 命令提交已在前次提交保留。本次增加可选 QSPI 预拷贝 profile、Zephyr 可重放补丁、普通 surface 完整画面记录和下拉按可见字形预加载。
- 微雪任意小窗口测试未通过，不启用任意窗口发送；80 MHz 实体有毛刺，未作为日常配置。双 16 KiB/80 KiB 堆仅保留实验 profile，默认关闭。
- LCKFB 普通 surface 画面记录最多新增一帧 PSRAM，240×320 RGB565 为 153600 B，后续复用；微雪使用驱动既有 shadow，不重复申请。

## 验证

主机 90 项测试执行，89 通过、1 项因缺本地 POSIX host 跳过；两板构建、固件文档检查通过。

LCKFB 普通 surface 的稀疏绘制、十二区合并与显式事务三场景共 12 次取消后像素精确恢复、6 次确认退出通过；首次确认框在本次启动无预先截图条件下完成。用户实体确认返回框及取消后恢复正常。

LCKFB 同一固件的返回码细分复测连续主机监测 600.91 秒，12 组上拉确认取消/下拉关闭全部通过。最后完整应用心跳完成循环 20353；图形、IMU、音频、资源、陈旧样本错误均 0。IMU reads=20660、fresh=20658；BEGIN busy=307，实际返回码为 ASTER_EBUSY (-5)，present busy=0，关闭面板后继续绘制。系统面板占屏时的 EBUSY 为预期退让，不计为渲染错误。

此前一轮测试未记录具体 rc，把所有非零 BEGIN 返回均记作绘图错误，不能将前轮计数当作 SPI/DMA 故障证据；原始记录保留。复测预检查曾误计成功的正命令数量，修正后重新启动完整十分钟，该预检查不计为通过时长。

微雪连续主机监测 600.16 秒，十组返回确认/取消通过；图形、音频、资源错误均 0，实体画面、触摸和返回确认由用户确认。IMU 按正式配置禁用；音频有功放 GPIO 告警且素材幅度低，不声称扬声器实听通过。

LCKFB 内核堆峰值 35660/49152 B，复测采样最小剩余 16320 B；微雪峰值 41764/49152 B。并发时两板最大连续空闲 PSRAM 块均至少 5 MiB，这是探测下界，不是总空闲统计。

下拉面板准备耗时：微雪原来 1229/1348/1347 ms，按可见字形预加载后为 202/33/33 ms；LCKFB 为 441/21/14 ms。数字包含 snapshot 和面板 build，不含后续 LVGL 渲染及物理传输。两板均获用户确认停顿明显改善、文字与动画正常。

帧计数包含主动取消的事务，不作为物理面板 FPS。软件注入触摸不替代真实触摸长期耐久。临时包已清理，原 APP/存档保留，恢复原前台应用与本轮开始时的音量。

原始串口、截图、测试包与镜像 SHA256 保留本地 diagnostics，不加入 Git。后续更改镜像后需重新确定验证适用范围。
