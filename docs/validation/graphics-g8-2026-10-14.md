# G8 字体与图片质量验收（已完成）（2026-10-14）

状态：代码、主机回归及LCKFB/微雪两板基础实机与实体检查完成，12px C字库已正式同步。微雪冷绘制延迟作为明确限制转G9跟踪；本项完成不代表该延迟已修复或物理I/O故障恢复已验证。未提交、未发布新SDK成品。

## 改动与边界

保持12/14/16等原生字号、既有排版、整数文字坐标及16级覆盖率；只更新12px字形，其他字号资源不变，没有扩大字形缓存。当前字体读取/预热为同步操作，没有字形后台队列；原生字体路由、页面预热、Scene测量和布局缓存继续复用。

APP/GFX与Pretty Poly共享的RGB565混合改为原生5/6位通道舍入一次：`(d*(255-a)+s*a+127)/255`。旧实现先扩展到8位再偏移量化，可能令相同前后景也变亮；修复后保持端点、同色恒等、交换对称和通道范围。TEXT显式指定背景时，覆盖率现在与该背景混合，不继续掺入旧画面；透明文字仍需调用者恢复旧背景。没有承诺字体光栅本身变得更高分辨率。

`aster sys fonts`增加累计命中、成功冷读取时长/最长耗时、同步预热耗时；保留原有缺失、淘汰、字节和各字号分配计数。只增加16B累计计数，无新队列/大缓冲。计数为启动以来的32位累计值，包含launcher与APP及页面准备；不能直接当作单次APP命中率。冷读计时只涵盖成功加载，失败不算入load_us。

SDK提供可选离线 `tools/prepare_image.py`：从原图一次生成实际尺寸，像素画最近邻，照片Lanczos，预乘颜色过滤透明边缘，明确底色后输出RGB PNG/BMP，默认拒绝放大及覆盖原图。依赖独立可选Pillow环境，普通APP编译不依赖；便携SDK只携带脚本/依赖清单，不新增图片处理EXE。launcher独立alpha图标继续使用ASTI RGB565A8；GFX黑色透明键/PNG合成黑底的限制未改变。

模拟器图片命令同步原生RGB565混合、整数最近邻、色键和裁剪；PNG独立alpha先合成黑底，fit尺寸与固件一样四舍五入。每bitmap延迟缓存2B/源像素的565副本，随句柄释放。不同系统文字光栅器不作字形像素完全一致承诺；固定A8遮罩的混合可逐像素比较。修正公开契约注释中已失效的tiny_ttf回退说明，未改变ABI号或imports，重新导入SDK并同步模拟器契约哈希；后续提交SDK时仍需同步模拟器固定提交。
