# Launcher Wi-Fi 与顶部下拉修复

状态：LCKFB 自动实机检查通过；微雪日常固件编译通过，尚未实机补测。本记录不替代人工触摸确认。

## 行为与原因

Wi-Fi 原关闭回调固定调用下拉栏 dismiss，从 launcher 调音台直接打开时没有对应栏可删除。设置页现接收所属容器的关闭回调：launcher 入口删除自身，APP 下拉入口关闭整栏并恢复保存的应用画面。设置页按父容器内容尺寸铺满，取消原来的减8像素及圆角；下拉入口对应容器也铺满屏幕。

Launcher 右上角小按钮移除，从顶部边缘向下滑动打开原调音台。右侧48个设计像素预留状态区，未提供电量驱动时不显示虚构电量。手势复用 APP 的识别器，起点在顶部28个逻辑像素内，纵向移动至少24像素且超过横向移动的1.5倍；不将卡片区滑动映射到调音台。识别成功后抑制本次触摸产生的控件点击；普通顶部“收回”点按仍有效。Wi-Fi、模态框、下拉栏或启动动画期间不启用此入口，调音台已打开时也不重复打开。调音台内从底部28个逻辑像素范围开始向上移动至少24像素、纵向超过横向1.5倍即可收回主页；此映射只关闭调音台，不发起APP退出。亮度/音量滑杆区域的滑动不会触发收回，Wi-Fi子页面保持自己的返回操作。
