# 连续音效 4.1.0-rc.1 候选版本

对应 SDK `sdk-v4.1.0-rc.1`，ABI 4.1.0。代码从 `feature/continuous-audio` 发布，不代表完整音频优化方案已经完成。

新增循环、交叉淡化、Q16音高与增益平滑、独立音效停止；四槽、每槽64KiB保持。SDK新导入要求最低ABI4.1；原4.0应用继续兼容。

已完成的微雪600.57秒单声部循环观察及主机检查见 [实施记录](continuous-audio-implementation.zh-CN.md)。当前发布仅执行打包所需编译和产物完整性核对，不追加实机或压力测试。

已知限制：无缝切歌、独立BGM停止、SD/解码/输出解耦以及OutRun接入尚未完成；Windows模拟器的Trap报告测试存在间歇访问异常；微雪仍有已知非法触摸报文警告。LCKFB本轮仅编译通过。不得将候选版当作完整方案验收通过。

开发包绑定固件/模拟器源码提交、SDK公开契约提交和各产物SHA-256。SDK最终打包提交只补充配套关系时，模拟器的sdkCommit指向明确记录的sdk_contract_revision；公开头文件与API哈希仍须完全相同，不能仅检查ABI版本字符串。
